# 💕 双人大富翁 v3.0（异地联机版）

一个给两个人的、能在手机浏览器里**异地一起玩**的大富翁游戏。
**40 格标准环形棋盘**，色组垄断、建房酒店、拍卖抵押，6 种情侣小游戏，4 种模式。

- **40 格环形棋盘**：格子沿四边围成一圈、四角特殊格、中央情侣主题景观（AI 生图）
- **房间号联机**：一人建房拿 6 位房间码，对方输入即加入；断线自动重连 + 落盘存档
- **四种模式**：经典对战 / 竞速 / 合作通关 / 心跳模式（默契值共同获胜）
- **完整大富翁经济**：8 色组垄断（租金翻倍）、建房→酒店（5 级）、拍卖、抵押赎回、车站/公用事业、机会/命运卡 16+16 张、免租券
- **6 种小游戏**：石头剪刀布、答题挑战、幸运转盘、默契问答、双人任务、默契大冒险
- **动作与人物**：骰子 3D 翻滚、棋子逐格移动（动画掩盖网络延迟）、角色头像棋子、买地/收租/监狱特效、Web Audio 音效、彩带庆祝、悄悄话
- **节奏可选**：悠闲 / 标准 / 快节奏（快节奏带「快骰」）
- **两套主题**：城市冒险 / 校园时光（价格与工资按比例缩放）

---

## 一、怎么玩（两人）

1. 一人点「创建房间」，选**主题 / 模式 / 节奏**，拿到 6 位房间号；
2. 把房间号发给对方，对方输房间号加入；
3. 两人到齐，房主点「开始游戏」；
4. 轮流掷双骰 → 棋子**沿环形棋盘逐格移动** → 落地触发事件；
5. 经过起点领工资（+250）；空地可买下，集齐**同色组**后租金翻倍并可建房；
6. 踩到对方地皮付过路费；有「免租券」自动抵扣一次；
7. 不买的地进入**两人竞价拍卖**；缺钱可**抵押**地产周转；
8. 进监狱可交 50 保释、掷双数出狱，或关满 3 回合强制出狱。

### 四种模式胜负规则

| 模式 | 获胜条件 |
|---|---|
| 经典对战 | 对手破产立即胜；否则回合上限后按净资产多者胜 |
| 竞速模式 | 最先绕棋盘 2 圈者胜 |
| 合作通关 | 两人合计净资产达 5200 共同获胜；任一方破产则失败 |
| 心跳模式 | 两人攒满 5 点默契值共同获胜（默契问答 +2、双人任务/大冒险 +1、命运卡 +1、**两人落在同一格 +1**） |

> 节奏影响回合上限：悠闲 ×1.4 / 标准 ×1 / 快节奏 ×0.65，且快节奏有概率触发「快骰」额外步数。

## 二、本地运行

```bash
npm install
npm start
```

浏览器打开 `http://localhost:3000`（`PORT` 环境变量可改端口）。
同一 WiFi 下两台设备可用局域网 IP 直接联机。

## 四、文件结构（v3.0 起改为多文件）

```
server.js              # 权威服务器：40 格数据/规则/经济/小游戏/胜负/同步/存档/重连
package.json           # 依赖 express + socket.io，npm start
public/
  index.html           # 大厅 / 等待 / 游戏 / 弹窗 / 结束屏
  style.css            # 马卡龙皮肤 + 11×11 环形棋盘 + 动画
  game.js              # 环形渲染 / 逐格移动 / 乐观 UI / DOM 复用 / 音效
  assets/              # 16 个 AI 生图切片的静态素材（共约 544KB）
    board-center.webp  bg-lobby.webp  char-boy/girl.webp
    avatar-boy/girl.png  ic-*.png（10 个道具图标）
saves/                 # 运行时自动生成的落盘存档（已忽略）
游戏优化完整方案.html   # v3.0 完整优化方案书（含竞品参考与分期路线）
```

> v2.x 是「单文件 base64 内嵌」。v3.0 因引入大量图片素材，改为多文件 +
> `express.static` 托管（图片可缓存），否则内嵌会让 `server.js` 膨胀到 MB 级、拖慢手机首屏。
> 静态资源带 `?v=3` 版本号，更新时改版本号即可破缓存。

## 五、自定义 & 扩展（数据驱动）

- **棋盘结构**：`LAYOUT`（40 项模板，含 `t` 类型 / `g` 色组 / `p` 价格 / `k` 小游戏候选）；
  地图名在 `CITY_NAMES` / `CAMPUS_NAMES`，主题配置在 `THEMES`。
  **监狱位置由 `findTile(tiles,'jail')` 按类型查找，不再硬编码索引**。
- **环形坐标**：`tileRC(i)` 把线性索引映射到 11×11 网格外圈（顺时针闭合），前后端共用同一映射。
- **色组/建房**：`GROUPS`（颜色、建房成本）、`rentOf`（垄断 ×2、1–4 房、酒店阶梯）、
  `buildHouse`（需垄断 + 均匀建造）、`mortgage`（抵押/赎回）。
- **卡片**：`CARD_POOLS.chance/destiny` 各 16 张；`QUIZ_POOL` 20 题、`BOND_POOL` 12 题、
  `DARE_POOL` / `COOP_POOL`；`WHEEL_PRIZES`。
- **模式与节奏**：`MODES` / `PACES`；平衡数值（起始 2000、工资 250、租金系数）集中在 `THEMES` 与 `rentOf`。
- **灰度开关**（env 变量，默认全开）：`FEATURE_ANIM`、`FEATURE_EXTRA_RULES`、`FEATURE_DELTA_SYNC`。

## 六、同步与性能设计

- **服务器权威**：双方只发意图，服务器结算后广播；客户端不决定结果。
- **瘦身状态**：静态 `tiles`（40 格定义 + 色组 + 坐标）只在开局/重连通过 `board` 事件下发一次；
  常规 `state` 只带动态摘要 `tileDyn`（每格 3 个数字）+ 最近 10 条日志。
  实测单次 state 约 **1.5KB**（v2.x 全量约 6–10KB）。
- **版本号**：`ver` 单调递增；`boardVersion` 变化时前端自动 `requestSync`。
- **动画掩盖 RTT**：`moveSteps` 路径序列 + `moveId` 去重，前端逐格播放（约 165ms/格），
  一次往返被动画自然覆盖；`mover` 显式下发移动方，不靠前端猜。
- **乐观 UI**：点骰子立即本地反馈 + 4.2 秒无响应自愈（不会永久卡住）。
- **DOM 复用**：40 个格子只建一次，state 更新只改 class / 文本 / 归属色条，不做 `innerHTML` 全量重建。
- **写盘防抖**：`persistRoom` 400ms 防抖，避免回合内重复全量序列化。
- **断线重连**（v2.2 保留）：握手带 `token` 自动重绑新 `socket.id`；找不到房间下发 `needResync`；
  旧版 20 格存档因 `boardVersion` 不匹配自动作废，不会索引错位。

## 八、更新日志

### v3.0（2026-11-11）— 从「网格小游戏」升级为「真正的 40 格环形大富翁」

按《游戏优化完整方案》一次性落地四大方向：

- **功能**：20 格 5×4 网格 → **40 格标准环形**（22 街区分 8 色组 + 4 车站 + 2 公用 + 12 功能格）；
  新增垄断租金翻倍、建房→酒店、拍卖、抵押赎回、免租券、爱心红包、16+16 卡池、
  默契问答/幸运转盘/双人任务/默契大冒险（共 6 种小游戏）、心跳模式、三档节奏 + 快骰。
- **UI**：马卡龙软萌 3D 皮肤，AI 生图 4 张 → 切成 16 个静态素材（棋盘中央景观、
  男女角色立绘/头像、10 个道具图标、大厅背景），裁切避开水印；CSS 画骰子点数不依赖 emoji 字体。
- **动作人物**：骰子翻滚、棋子逐格移动跳跃、买地/收租/监狱/默契特效、彩带庆祝、
  Web Audio 合成音效（可静音）、角色表情棋子、两人同格爱心彩蛋。
- **延迟卡顿**：静态数据分离 + `tileDyn` 瘦身（1.5KB/次）、`ver`/`boardVersion` 版本号、
  `moveSteps`+`moveId`+`mover` 动画插值、乐观 UI + 超时自愈、DOM 复用、写盘防抖、日志分页。
- **稳定性修复**：`setFx` 曾覆盖 `lastEvent.tile` 导致买地崩溃 → 独立 `buyTile`；
  小游戏结算改用稳定玩家下标 `actorIdx`，断线/超时只取消不结算，修复「双端断开导致服务崩溃」。
- **架构**：单文件 base64 → 多文件 + 静态资源托管；旧存档按 `boardVersion` 作废。
