# 💕 双人游戏合集 v3.2（异地联机版）

一个给两个人的、能在手机浏览器里**异地一起玩**的双人游戏合集。
当前可玩：**情侣大富翁**——**40 格标准环形棋盘**，色组垄断、建房酒店、拍卖抵押，
6 种情侣小游戏，4 种模式，外加 v3.1 的「模拟人生」与传送门捷径，
以及 v3.2 的**掷骰两步走 / 10 组头像 / 双人实时互动 / 岔路与共同决策**。

- **一个链接，多个游戏**：大厅顶部「🎮 双人游戏合集」选择条，当前 1 款可玩 + 占位卡；
  `gameKind` 贯穿房间/存档/重连，服务端 `GAME_KINDS` 注册表为后续小游戏留好分派接缝
- **40 格环形棋盘**：格子沿四边围成一圈、四角特殊格、中央情侣主题景观（AI 生图）
- **房间号联机**：一人建房拿 6 位房间码，对方输入即加入；断线自动重连 + 落盘存档
- **四种模式**：经典对战 / 竞速 / 合作通关 / 心跳模式（默契值共同获胜）
- **完整大富翁经济**：8 色组垄断（租金翻倍）、建房→酒店（5 级）、拍卖、抵押赎回、车站/公用事业、机会/命运卡 22+22 张、免租券
- **v3.1 模拟人生**：🏦 银行存钱（每圈 +8% 利息）、💳 借款（每圈自动还 100）、💌 转赠红包、
  🚗 买车（之后几次多走 2 格）、🎭 人生驿站双选情境（升学/买车/生日/理财/加班/伤病…）、
  🌀 成对传送门捷径；净资产计入存款、负债与车辆，现金不足时自动取存款垫付
- **6 种小游戏**：石头剪刀布、答题挑战、幸运转盘、默契问答、双人任务、默契大冒险
- **动作与人物**：**3D 立方体骰子**（转动 3D → 落定展平 2D）、棋子逐格移动（约 200ms/格）、
  **棋子旁「📍 你在这里」位置气泡**、地点真实图片、买地/收租/监狱/传送特效、Web Audio 音效、彩带庆祝
- **体验修补（v3.1）**：悄悄话**弹窗式气泡 + 未读角标**、顶栏 🏠 退出房间 / ⚙️ 设置（音效、
  重开本局、退出、玩法速览）、结束屏与等待页返回大厅、弹窗延后到移动动画落定再出现
- **v3.2 掌控节奏**：掷骰与前进拆成两步——骰子先翻滚落定显示点数，
  面板出现绿色「👣 前进 N 步」按钮，**点前进棋子才移动**，双方都看得清、不再一闪而过

## 一、怎么玩（两人）

1. 一人点「创建房间」，选**主题 / 模式 / 节奏**，拿到 6 位房间号；
2. 把房间号发给对方，对方输房间号加入；
3. 两人到齐，房主点「开始游戏」；
4. 轮流点「🎲 掷骰子」→ 3D 骰子翻滚落定**先显示点数**，再点绿色「👣 前进 N 步」→
   棋子沿环形棋盘逐格移动，气泡实时标出所在地点（**两步走，节奏由你掌控**）；
5. 经过起点领工资（+250）；空地可买下，集齐**同色组**后租金翻倍并可建房；
6. 踩到对方地皮付过路费；有「免租券」自动抵扣一次；
7. 不买的地进入**两人竞价拍卖**；缺钱可**抵押**地产周转；
8. 进监狱可交 50 保释、掷双数出狱，或关满 3 回合强制出狱；
9. 踩到 🏦 银行 / 🎭 人生驿站会弹出**人生选择**（存/取/借，或双选情境）；
   踩到 🌀 传送门会瞬移到成对的另一扇门；
10. 顶栏 ⚙️ 可随时**重开本局**（双方回等待页）或 🏠 **退出房间**（解散并通知对方）。

### 四种模式胜负规则

| 模式 | 获胜条件 |
|---|---|
| 经典对战 | 对手破产立即胜；否则回合上限后按净资产多者胜 |
| 竞速模式 | 最先绕棋盘 2 圈者胜 |
| 合作通关 | 两人合计净资产达 5200 共同获胜；任一方破产则失败 |
| 心跳模式 | 两人攒满 5 点默契值共同获胜（默契问答 +2、双人任务/大冒险 +1、命运卡 +1、**两人落在同一格 +1**、人生选择/红包也可 +1~2） |

> 节奏影响回合上限：悠闲 ×1.4 / 标准 ×1 / 快节奏 ×0.65，且快节奏有概率触发「快骰」额外步数。

## 四、文件结构（v3.0 起多文件，v3.2 沿用）

```
server.js              # 权威服务器：合集注册表/40 格数据/规则/经济/小游戏/
                       #   模拟人生/传送门/人生选择/胜负/同步/存档/重连
package.json           # 依赖 express + socket.io，npm start
public/
  index.html           # 游戏合集条 / 大厅 / 等待 / 游戏 / 弹窗 / 设置 / 结束屏
  style.css            # 马卡龙皮肤 + 11×11 环形棋盘 + 3D 骰子 + 位置气泡 + 动画
  game.js              # 环形渲染 / 逐格移动 / 3D 骰子 / 位置气泡 / 悄悄话 /
                       #   人生选择 / 设置 / 乐观 UI / DOM 复用 / 音效
  assets/              # 24 个静态素材（16 个 AI 生图切片 + 8 个程序化 SVG 头像）
    board-center.webp  bg-lobby.webp  char-boy/girl.webp
    avatar-boy/girl.png  ic-*.png（10 个道具图标，v3.1 起格子也用上了）
    av-*.svg（8 个 Q 版动物头像，v3.2 新增）
saves/                 # 运行时自动生成的落盘存档（已忽略）
游戏优化完整方案.html   # v3.0 完整优化方案书（含竞品参考与分期路线）
```

> v2.x 是「单文件 base64 内嵌」。v3.0 因引入大量图片素材，改为多文件 +
> `express.static` 托管（图片可缓存），否则内嵌会让 `server.js` 膨胀到 MB 级、拖慢手机首屏。
> 静态资源带版本号查询串，更新时改版本号即可破缓存（当前 `style.css?v=6`、`game.js?v=5`）。

### 为什么先做「合集外壳」而不物理拆分规则文件

一个链接里放多款双人小游戏，最值钱、最难重写的是**共享底座**：房间码、token 断线重连、
`saves/` 存档、`ver`/`boardVersion` 瘦身同步、写盘防抖、乐观 UI 自愈。拆成多个独立链接等于复制多份，
以后修一个重连 bug 要改多处；先合后拆远比先拆后合容易。

v3.1 落地的是**可见的外壳与数据接缝**：`GAME_KINDS` 注册表、`room.gameKind`
（贯穿 `createRoom`/`boardState`/`publicState`/`persistRoom`/`loadSaves`/重连）、大厅选游戏条。
**规则仍留在 `server.js`，未做物理抽文件**——那是纯内部重构、零用户可感知价值，
且会改动全部已通过 E2E 的核心路径。真正该抽的时机是「塞进第 2 个游戏」时，
带着具体规则边界一次性抽到 `games/<kind>.js`，成本更低、边界更准。

## 五、自定义 & 扩展（数据驱动）

- **棋盘结构**：`LAYOUT`（40 项模板，含 `t` 类型 / `g` 色组 / `p` 价格 / `k` 小游戏候选 / `pair` 传送配对）；
  地图名在 `CITY_NAMES` / `CAMPUS_NAMES`，主题配置在 `THEMES`。
  **监狱位置由 `findTile(tiles,'jail')` 按类型查找，不再硬编码索引**。
  v3.1 只把 4 个功能格换成 `bank` / `life` / `portal ×2`，**40 格、22 街区、8 色组、4 角、监狱 idx=10 全部保持不变**。
- **环形坐标**：`tileRC(i)` 把线性索引映射到 11×11 网格外圈（顺时针闭合），前后端共用同一映射。
- **色组/建房**：`GROUPS`（颜色、建房成本）、`rentOf`（垄断 ×2、1–4 房、酒店阶梯）、
  `buildHouse`（需垄断 + 均匀建造）、`mortgage`（抵押/赎回）。
- **卡片与情境**：`CARD_POOLS.chance/destiny` 各 22 张（v3.1 新增存款/取款/借款/转赠/买车/
  人生事件/传送）；`LIFE_EVENTS` 8 组双选情境；`QUIZ_POOL` 20 题、`BOND_POOL` 12 题、
  `DARE_POOL` / `COOP_POOL`；`WHEEL_PRIZES`。
- **人生选择框架**：`startChoice` / `resolveChoice` / `applyLifeEffect`，与 `await_buy` 同构的
  `await_choice` phase + `choicePick` 事件，银行与人生驿站共用一套弹窗，等当事人决定后才推进回合。
- **模拟人生资产**：玩家 `savings` / `loan` / `cars` / `carBoost`；过起点结算利息与还贷；
  `netWorth` 计入存贷款与车辆；`checkBankrupt` 先用存款垫付；买车后掷骰 +2 步。
- **游戏合集**：`GAME_KINDS` 注册表 + `room.gameKind`，新增游戏只需补一个分支。
- **模式与节奏**：`MODES` / `PACES`；平衡数值（起始 2000、工资 250、租金系数）集中在 `THEMES` 与 `rentOf`。
- **灰度开关**（env 变量，默认全开）：`FEATURE_ANIM`、`FEATURE_EXTRA_RULES`、`FEATURE_DELTA_SYNC`。

## 六、同步与性能设计

- **服务器权威**：双方只发意图，服务器结算后广播；客户端不决定结果。
- **瘦身状态**：静态 `tiles`（40 格定义 + 色组 + 坐标）只在开局/重连通过 `board` 事件下发一次；
  常规 `state` 只带动态摘要 `tileDyn`（每格 3 个数字）+ 最近 10 条日志。
  实测单次 state 约 **1.7KB**（v2.x 全量约 6–10KB）。
- **版本号**：`ver` 单调递增；`boardVersion` 变化时前端自动 `requestSync`。
  v3.2 因新增 `await_move`/头像/互动字段与卡池升级到 **BOARD_VERSION=5**，旧存档按现有机制自动作废。
- **动画掩盖 RTT**：`moveSteps` 路径序列 + `moveId` 去重，前端 3D 骰子约 950ms +
  逐格约 200ms/格，一次往返被动画自然覆盖；`mover` 显式下发移动方，不靠前端猜。
  v3.2 拆出 `diceId`：骰子动画与移动动画**独立去重**，点「前进」才播移动序列；
  自定义头像走 `avatarImage` 独立事件、不进 `state`，单次 state 仍约 1.7KB。
  **买地/人生选择弹窗延后到移动动画落定才弹出**，不遮挡动画。
- **乐观 UI**：点骰子立即本地反馈 + **6 秒**无响应自愈（配合变慢的动画，不会永久卡住）。
- **DOM 复用**：40 个格子只建一次，state 更新只改 class / 文本 / 归属色条，不做 `innerHTML` 全量重建。
- **写盘防抖**：`persistRoom` 400ms 防抖，避免回合内重复全量序列化。
- **断线重连**（v2.2 保留）：握手带 `token` 自动重绑新 `socket.id`；找不到房间下发 `needResync`；
  旧版存档因 `boardVersion` 不匹配自动作废，不会索引错位。
- **主动离开**（v3.1）：`leaveRoom` 解散两人房并广播 `roomClosed` 给对方（对方不会被留在原地）；
  `endSession` 清对局但保留房间，双方一起回等待页重新配置；`restart` 仍用于结束屏再来一局。
