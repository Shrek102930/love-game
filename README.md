## 一、怎么玩（两人）

1. 一人点「创建房间」，选**主题 / 模式 / 节奏**，拿到 6 位房间号；
2. 把房间号发给对方，对方输房间号加入；
3. 两人到齐，房主点「开始游戏」；
4. 轮流点「🎲 掷骰子」→ 3D 骰子翻滚落定**先显示点数**，再点绿色「👣 前进 N 步」→
   棋子沿环形棋盘逐格移动，气泡实时标出所在地点（**两步走，节奏由你掌控**）；
   **踩到 🛤️ 岔路口时面板变成两个按钮**——「外环 N 步」正常走，或「🛤️ 走内环」拐进内环，
   经过 12 个「心跳小站」抄近道（奖池滚存、摩天轮、共同宝箱、双人任务、许愿池…经过即结算、双人向）；
5. 经过起点领工资（+250）；空地可买下，集齐**同色组**后租金翻倍并可建房；
6. 踩到对方地皮付过路费；有「免租券」自动抵扣一次；
7. 不买的地进入**两人竞价拍卖**；缺钱可**抵押**地产周转；
8. 进监狱可交 50 保释、掷双数出狱，或关满 3 回合强制出狱；
9. 踩到 🏦 银行 / 🎭 人生驿站会弹出**人生选择**（存/取/借，或双选情境）；
   踩到 🌀 传送门会瞬移到成对的另一扇门；
10. 顶栏 ⚙️ 可随时**重开本局**（双方回等待页）或 🏠 **退出房间**（解散并通知对方）。

### 共享小花园怎么玩（v4.0）

1. 大厅选「🌷 共享小花园」→ 建房 / 加入（同样 6 位房间码），房主开始；
2. 进入一片 **2.5D 等距菱形土地**，两人**同屏共享同一块地**，谁改了对方立刻看到；
3. 在工具条**先选道具再点空地**：4 种花（玫瑰 / 郁金香 / 向日葵 / 星星花，5 金币）
   或 4 种装饰（长椅 / 路灯 / 喷泉 / 秋千，20 金币）；金币是**两人共用**的；
4. 种下的植物按真实时间成长：**种子 → 发芽 → 开花**（本地定时重算，无需轮询服务器），
   切「💧 浇水」工具点一下可催长；
5. **双人动作**：📅 签到、💐 送花、🌳 合种树（**两个人都添一铲土**才长成）、💌 长椅留言、
   💗 比心 / 送礼等互动条；**爱心值只由这些共同动作累加**；
6. 顶栏悄悄话、音效、设置、退出与大富翁共用；设置里「重置花园」等于两个人一起重新开垦。

> 花园不设胜负、不拼手速，是「一起慢慢经营」的异步陪伴型玩法：
> 今天种下，明天回来花就开了；`GARDEN_VERSION=1` 存档落盘，断线重连不丢。

### 四种模式胜负规则

| 模式 | 获胜条件 |
|---|---|
| 经典对战 | 对手破产立即胜；否则回合上限后按净资产多者胜 |
| 竞速模式 | 最先绕棋盘 2 圈者胜 |
| 合作通关 | 两人合计净资产达 5200 共同获胜；任一方破产则失败 |
| 心跳模式 | 两人攒满 5 点默契值共同获胜（默契问答 +2、双人任务/大冒险 +1、命运卡 +1、**两人落在同一格 +1**、人生选择/红包也可 +1~2） |

> 节奏影响回合上限：悠闲 ×1.4 / 标准 ×1 / 快节奏 ×0.65，且快节奏有概率触发「快骰」额外步数。

### 为什么先做「合集外壳」而不物理拆分规则文件

一个链接里放多款双人小游戏，最值钱、最难重写的是**共享底座**：房间码、token 断线重连、
`saves/` 存档、`ver`/`boardVersion` 瘦身同步、写盘防抖、乐观 UI 自愈。拆成多个独立链接等于复制多份，
以后修一个重连 bug 要改多处；先合后拆远比先拆后合容易。

v3.1 落地的是**可见的外壳与数据接缝**：`GAME_KINDS` 注册表、`room.gameKind`
（贯穿 `createRoom`/`boardState`/`publicState`/`persistRoom`/`loadSaves`/重连）、大厅选游戏条。
**规则仍留在 `server.js`，未做物理抽文件**——那是纯内部重构、零用户可感知价值，
且会改动全部已通过 E2E 的核心路径。v4.0 已经「塞进第 2 个游戏」（共享小花园），
验证过共用底座确实够用：`GAME_KINDS` 注册 + `boardState`/`publicState`/`startGame`
按 `gameKind` 分流，花园所有动作收敛到一个 `gardenAction` 事件，`publicState` 里
`room.game` 为空的房间由 `gardenPublicState` 独立下发，大富翁专属 handler 全部加 garden guard。
**规则仍留在 `server.js`，未做物理抽文件**——那是纯内部重构、零用户可感知价值；
等第 3 款游戏进来、边界更清楚时再一次性抽到 `games/<kind>.js`。

## 五、自定义 & 扩展（数据驱动）

## 六、同步与性能设计

- **服务器权威**：双方只发意图，服务器结算后广播；客户端不决定结果。
- **瘦身状态**：静态 `tiles`（52 格定义：外环 40 + 内环 12，含色组 / 坐标 / 岔路标记）只在开局/重连通过 `board` 事件下发一次；
  常规 `state` 只带动态摘要 `tileDyn`（外环 40 格、每格 3 个数字）+ 最近 10 条日志。
  实测单次 state 约 **1.7KB**（v2.x 全量约 6–10KB）。
- **版本号**：`ver` 单调递增；`boardVersion` 变化时前端自动 `requestSync`。
  v3.3 因双环棋盘 / 岔路 / 内环小站升级到 **BOARD_VERSION=6**，旧存档按现有机制自动作废。
  v4.0 花园独立用 **GARDEN_VERSION=1**，`loadSaves` 按 `gameKind` 分别校验（花园房验 `gardenVersion`、
  大富翁房验 `boardVersion`），互不影响；`gardenPublicState` 同时下发 `boardVersion` 以免前端无限 `requestSync`。
- **动画掩盖 RTT**：`moveSteps` 路径序列 + `moveId` 去重，前端 3D 骰子约 950ms +
  逐格约 200ms/格，一次往返被动画自然覆盖；`mover` 显式下发移动方，不靠前端猜。
  v3.2 拆出 `diceId`：骰子动画与移动动画**独立去重**，点「前进」才播移动序列；
  自定义头像走 `avatarImage` 独立事件、不进 `state`，单次 state 仍约 1.7KB。
  **买地/人生选择弹窗延后到移动动画落定才弹出**，不遮挡动画。
- **乐观 UI**：点骰子立即本地反馈 + **6 秒**无响应自愈（配合变慢的动画，不会永久卡住）。
- **DOM 复用**：52 个格子（外环 40 + 内环 12）只建一次，state 更新只改 class / 文本 / 归属色条，不做 `innerHTML` 全量重建。
- **写盘防抖**：`persistRoom` 400ms 防抖，避免回合内重复全量序列化。
- **断线重连**（v2.2 保留）：握手带 `token` 自动重绑新 `socket.id`；找不到房间下发 `needResync`；
  旧版存档因 `boardVersion` 不匹配自动作废，不会索引错位。
- **主动离开**（v3.1）：`leaveRoom` 解散两人房并广播 `roomClosed` 给对方（对方不会被留在原地）；
  `endSession` 清对局但保留房间，双方一起回等待页重新配置；`restart` 仍用于结束屏再来一局。

### v4.4.1（2026-11-11）— 大富翁两个回归修复：自定义头像 + 窄屏棋盘

玩后反馈「我玩家自定义的头像和名字没加载」「地图右边超出屏幕边界看不到」，逐条复现定位后修复。

- **自定义头像开局被重置（根因在服务端 `buildGame`）**：`AVATAR_IDS` 只含 10 个内置头像，不含 `'custom'`；
  开局时 `if (!p.avatar || !AVATAR_IDS.includes(p.avatar)) p.avatar = 'boy'/'girl'` 会把建房时已设置好的
  **自定义照片判定为非法并打回默认头像** —— 所以等待页能看到自定义头像、一进游戏就变回内置小人。
  修复：条件加 `&& p.avatar !== 'custom'`，保留自定义头像；`createRoom` / `joinRoom` 同样接受 `'custom'`。
- **后加入者看不到对方自定义头像**：`avatarImage`（自定义图走独立事件，不进 state）只在 `setAvatar` 时广播，
  后加入的玩家收不到先到者那一条。修复：`joinRoom` 开局前把房间内已有的自定义头像重新广播一次，双方都能看到。
- **昵称回填**：大厅 `#nameInput` 现在用上次保存的 `S.name` 回填，不用每次重输（名字本身服务端一直有下发，未丢）。
- **窄屏棋盘右缘超出屏幕（根因在 CSS）**：`@media (max-width:360px)` 里 `.board{min-width:376px}` 强制棋盘
  比 320/360px 的屏幕还宽，`body{overflow-x:hidden}` 直接把右侧裁掉、又不能横向滚动 → 右列格子永远看不到。
  修复：改为 `min-width:0` 让棋盘缩到满宽自适应；并取消该断点下 `.board-frame{margin:0 -8px}` 的负外扩
  （实测 320px 时棋盘框 326px 宽，产生 3px 横向滚动），改 `margin:0`。320px 实测 `scrollWidth=320`、零溢出。
- **版本**：`app-version=v4.4.1`、`style.css?v=13`、`game.js?v=12`。
- **验证**：真实浏览器双手机（双方各用不同自定义头像、含后加入者）E2E **10/10 全绿** ——
  双方棋子 / HUD 头像均为自定义、双方昵称正确、320px 棋盘右缘在屏内且无横向滚动、零 JS 报错；
