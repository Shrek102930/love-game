# 💕 双人大富翁（异地联机版）

一个给两个人的、能在手机浏览器里**异地一起玩**的大富翁小游戏。

- **房间号联机**：一个人建房拿 6 位房间码，发给对方，对方输入即加入
- **三种玩法模式**：经典对战 / 竞速 / 合作通关
- **小游戏格**：石头剪刀布、答题挑战，两人实时互动
- **随机卡片 + 多地图主题**：城市 / 校园，每局充满变数
- **断线重连 + 落盘存档**：掉线或刷新自动回到原房间续玩，服务器重启也不丢
- **悄悄话聊天**：游戏里还能互发消息

---

## 一、怎么玩（两人）

1. 一个人点「创建房间」，选好**地图主题**和**玩法模式**，拿到 6 位房间号；
2. 把房间号发给对方，对方点「输入房间号加入」；
3. 两人到齐后，创建者点「开始游戏」；
4. 轮流掷骰 → 移动 → 落地触发事件（买地 / 交过路费 / 抽卡 / 进监狱 / 缴税 / 小游戏）；
5. 经过起点领工资；空地可花钱买下，买下的地可升级（提升过路费）；
6. 🎮 石头剪刀布：两人各出拳，胜者赢 60；
7. 🧠 答题挑战：落地者作答，答对 +80 / 答错 -40；
8. 进监狱可掷双数逃出、关满 3 回合交保释金，或主动交 50 出狱。

### 三种模式胜负规则
- **经典对战**：任一方破产立即结束；否则 30 圈后按净资产多者胜。
- **竞速模式**：最先绕棋盘 3 圈者获胜（破产则对方胜）。
- **合作通关**：两人合计净资产达 6000 即共同获胜；任一方破产则合作失败。

## 二、本地运行

```bash
npm install
npm start
```

手机/电脑浏览器打开 `http://<你电脑的局域网IP>:3000`（如 `http://192.168.1.20:3000`）。
查看本机 IP：`ipconfig`（Win）/ `ifconfig`（Mac/Linux）。
> 同一 WiFi 下两台设备可直接用局域网 IP 一起玩。

## 三、异地一起玩（重点 · 成品关键）

两人不在同一网络时，最稳的做法是**把游戏部署到云**，拿到一个永久固定链接，随时发女朋友即可。
下面给的是**纯手机也能完成**的部署流程（用 Render 免费额度，无需信用卡）。

> 如果你有一台一直开着的电脑，也可以用 localtunnel / ngrok 临时把 `localhost:3000` 暴露出去，
> 但免费隧道经常断（实测 localtunnel 会偶发 503），不如部署到云省心。

### 手机部署到 Render（推荐 · 永久免费 · 固定链接）

一次性准备（约 5 分钟，全程手机浏览器）：
1. 注册 GitHub（github.com）——用来托管代码；
2. 注册 Render（render.com）——用来跑服务、给你公网地址。

部署步骤：
1. 在 GitHub 新建一个**公开仓库**（如 `love-game`）；
2. 用「Add file → Upload files」一次性上传这 **2 个文件**（项目已做成单文件版，无需 `public/` 文件夹）：
   - `server.js`（已内嵌前端页面，自包含运行）
   - `package.json`
3. 打开 render.com → 登录 → 右上角「New +」→「Web Service」；
4. 连你的 GitHub，选中该仓库；
5. 配置（Render 通常自动识别 Node，确认即可）：
   - Build Command：`npm install`
   - Start Command：`npm start`
   - Plan：**Free**
6. 点「Create Web Service」，等 1~2 分钟部署完成；
7. 顶部会出现形如 `https://love-game-xxxx.onrender.com` 的地址——**这就是永久固定链接**！

给女朋友：把上面这个地址发她，她浏览器打开 → 你点「创建房间」→ 把 6 位房间码发她 → 她「加入」即可。

> 注：Render 免费版 15 分钟无访问会休眠，第一次打开稍慢（几秒），之后正常；需要常驻可升级付费档。
> 备选平台：Railway（railway.app，同样免费额度，流程类似）、Fly.io、Vercel 等，均支持 Node。

## 四、自定义 & 扩展

代码为「数据驱动」，加内容基本只改数据、不动逻辑：

- **加地图主题**：在 `server.js` 的 `THEMES` 里照样子加一份。格子 `type` 支持：
  `go / property / chance / destiny / jail / gotojail / tax / park / minigame`
  （`minigame` 需带 `kind: 'rps'` 或 `kind: 'quiz'`）。
- **加卡片**：在 `CARD_POOLS` 的 `chance` / `destiny` 里加条目。
- **加/改答题**：在 `QUIZ_POOL` 里加题目（轻松向，适合情侣）。
- **改回合数 / 初始资金 / 工资 / 胜负目标**：调整 `buildGame` 与各 `MODES` 配置。
- **改棋盘大小**：直接增减 `tiles` 数组（监狱格固定为索引 5，别动它）。
- **落盘存档**：房间状态实时写入 `saves/<房间号>.json`，服务器重启后自动恢复。

## 五、文件结构

```
server.js        # 服务器 + 内嵌前端页面（单文件自包含）：房间/骰子/结算/广播/存档
package.json     # 依赖与启动命令（npm start）
```
> 前端 HTML/CSS/JS 已 base64 内嵌进 `server.js`，因此**只需这 2 个文件即可部署运行**，
> 无需 `public/` 目录。若要修改界面，从源码重建即可（参见 `.codebuddy` 下的构建脚本）。
> `saves/` 为运行时自动生成的存档目录（已在 .gitignore 类忽略，可删除）。

### v2.1（2026-11-11）— 手机端交互加固 + 模式显示修复

- **修复 `[undefined]` 模式名**：`publicState` 的 `game` 对象缺 `mode`/`modeName` 字段，

  绝不永久挡住所有点击。
- **掷骰子按钮吸底**（`position: sticky`）：任何屏幕尺寸、任何滚动位置都点得到；
  无可操作控件时整块隐藏，不留空白条。
- **开始游戏时重置滚动位置**、**连接状态提示条**（冷启动明确提示"正在连接"）、
  **等待页显示「已加入 1/2 / 2/2」**、**掷骰即时反馈**。
